# iptibi — downloads

Public distribution of the **iptibi** APKs (Android TV and Android phone/tablet).
Source code is not published here.

**Português:** Este repositório serve apenas para descarregar os APK do iptibi. Cada versão está na secção *Releases*; os ficheiros `SHA256SUMS.txt` contêm as somas de verificação. Versões marcadas como *pre-release* são experimentais.

**English:** This repository only hosts downloadable iptibi APKs. Each version is under *Releases*; the `SHA256SUMS.txt` file in each release contains the SHA-256 checksums. Versions marked *pre-release* are experimental.

## Install notes / Notas de instalação

- Verify the checksum before installing. / Verifique a soma de verificação antes de instalar.
- Allow installation from unknown sources if your device asks. / Permita a instalação de fontes desconhecidas, se o dispositivo pedir.
